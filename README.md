# 🎬 MovieExplorer

A modern, responsive React web application for exploring movies and TV shows powered by the **TVMaze API**. Built with **React 18**, **React Router v6**, **Tailwind CSS**, and **Vite**, featuring real-time search, interactive detail modals, clean client-side routing, and persistent page state.

---

## ✨ Features

- 🍿 **Explore Popular Shows:** Browse curated titles on launch with automatic fallback handling for missing poster images.
- 🧭 **Declarative Client-Side Routing:** Powered by **React Router v6** for seamless multi-page navigation and deep-link page persistence.
- 🔍 **Real-Time Live Search:** Search shows dynamically via TVMaze API with instant UI updates.
- 🎭 **Interactive Modal View:** Detailed overlay displaying high-res show art, release year, average ratings, genres, and HTML-sanitized summaries.
- 📱 **Fully Responsive Layout:** Built using Tailwind CSS grid and flex layouts for mobile, tablet, and desktop views.
- 🎨 **Sleek Dark Theme:** Dark UI designed with slate accents, indigo highlights, and an inline SVG film favicon.
- ⚡ **Lightweight & Fast:** Powered by Vite with server-side rewrite rules (`vercel.json`) to handle direct route reloads flawlessly.
